# Expense Tracker (React + Node.js)

This is a full-stack Expense Tracker application built using **React (Vite)** for the frontend and **Express.js** for the backend.  
It allows users to sign up, log in, and securely manage their expenses with JWT authentication.

---

## 🧩 Tech Stack

**Frontend**
- React (Vite)
- React Router
- Axios for API communication

**Backend**
- Node.js
- Express.js
- MySQL
